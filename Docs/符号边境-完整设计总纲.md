## 一、核心定位与灵感融合

**类型**：不对称语言推理博弈桌游（个人竞技计分）

**三重机制（无割裂）**：

1. **底层内核 =《第一类接触》**  
   无通用语言；每人独立私语法；纯诚实回答；语义歧义制造推理陷阱；符号特征破译是唯一主线。

2. **中层博弈 =《诺丁汉警长》**  
   自由贿赂；风险后置结算；权力位轮替；赌徒心理；交易背刺。

3. **顶层压力 =《Papers Please》**  
   每日变动法令；公职判决压力；误判惩罚；合规筛选主题。

**核心卖点（锁死）**：  
全程**无人说谎**。所有欺骗、误导、博弈全部来自「人与人语言体系不互通」。  
同时兼顾：推理深度、心理博弈、多人对抗、交易背刺、个人竞技计分。

## 二、基础信息

| 项 | 定稿 |
|---|---|
| 人数 | **3–4 人**（正式规则）；2 人见「附录 A」简化变体 |
| 时长 | 25–40 分钟 |
| 总轮数 | = 玩家人数（每人当且仅当一次检查员） |
| 胜利 | 个人累计总分最高者获胜；同分比「检查员正确判决次数」，再同分共享胜利 |
| 语言 | 桌上交流可用自然语言，但**质询回答只能「是/否」**；递交与游说发言受限（见流程） |

## 三、世界观（规则用短设定）

边境口岸存在多种异族文明。各族没有通用文字，只用古老符号组合表达族群特征与入境资格。每位异族拥有独属于自己文明的分类逻辑。边境法令每日变更；检查员必须从零破译每个人的私人语言，判断对方是否合规。

## 四、组件清单与数量（v1.0）

### 4.1 公共概念池（全局公开，10 词，全部有效）

`河流、果实、岩壁、火种、道路、羊群、石门、原野、航行、守望`

编号便于对照表：C1–C10 按上列顺序。

### 4.2 抽象符号卡（5 种几何符号）

建议形态：`○ △ □ ◎ ✦`（印刷可用任意五互不混淆几何形）。  
**数量**：每种 **4 张**，共 20 张。  
每轮：每人抽 **3** 张，打出 **1–2** 张，未打出者轮末弃置；弃牌堆洗匀补库。

### 4.3 个人秘则卡（绝对私密）

共 **12 张**（见第十节完整表）：  
- 逻辑域 **定居 S**：4 张  
- 逻辑域 **迁徙 M**：4 张  
- 逻辑域 **互助 H**：4 张  

每张含：逻辑域标签 + 符号→概念对照表 + 本轮「描述集合」生成规则。

### 4.4 入境身份档案卡

- **合规（绿）**：定居庇护族群 — 允许入境 · **8 张**  
- **违规（红）**：迁徙游牧族群 — 禁止入境 · **8 张**  

发牌规则见 10.4（与秘则、法令强制一致，禁止随机导致自相矛盾）。

### 4.5 法令卡

**6 张**（见 10.5），每大轮公开 1 张；用过的法令本局不重复（6 张够 3–4 轮；4 人局抽 4 张打乱成法令序列）。

### 4.6 筹码

- **信用筹码**（检查员专属，建议异色）：每轮检查员获得 **3** 枚；轮末清空回收。  
- **通用筹码**（贿赂 / 游说 / 交易货币）：建议 **40** 枚公共池。  
  - 3 人局起始每人 **6**  
  - 4 人局起始每人 **5**

### 4.7 其他

- 风险标记物 ×4（游说用）  
- 积分记录表 / 记分板 ×1  
- 密猜条（检查员轮末猜秘则逻辑域用）× 每人每轮 1 条，或用挡板 + 代币

### 4.8 明确无废组件原则

- 10 个概念全部可出现在至少 2 张秘则的「是」侧与「否」侧，避免恒真/恒假废问。  
- 不问「你是否合规」类直问（铁则）。  
- 符号本身无全局含义；全局只有概念池与法令模板。

## 五、底层铁则（游戏灵魂，绝对不能删）

1. **不存在通用符号翻译**  
   任一玩家的符号含义 100% 不可套用到另一玩家。

2. **所有回答绝对诚实**  
   对合法质询只能答「是」或「否」，禁止说谎、禁止拒答、禁止「不确定」。

3. **禁止跳步直问身份**  
   不得问：是否合规、是否迁徙、是否允许入境、你的逻辑域是什么、你的档案颜色等。  
   身份结论只能通过符号—概念推理 + 对照法令得出。

4. **禁止纯猜判决**  
   对某入境者**零合法质询**就判决：该次判决无论对错，额外 **-2**（见计分）。  
   「合法质询」= 消耗至少 1 信用、针对该入境者、符合提问句式。

5. **贿赂与游说不作合法判决依据**  
   规则书必须写明：收贿、风险标记、桌面协议均**不改变**档案真伪与法令判定。  
   检查员可受其心理影响，但结算只认档案 + 法令 + 判决动作。

## 六、全局轮替与每轮重置

1. 总轮数 = 玩家人数。  
2. 每轮固定 **1 名检查员**，其余为入境者。  
3. 轮换顺序开局议定（顺时针）；每人当且仅当一次检查员。

**每轮开局重置（顺序固定）**：

1. 翻开本轮 **法令卡**（公开）。  
2. 每人秘密抽 **1 张秘则卡**（按 10.4 与法令、档案联动发牌，见下）。  
3. 每人秘密获得 **1 张入境档案**（与秘则一致约束）。  
4. 每人从符号库抽 **3** 张符号手牌。  
5. 检查员获得 **3** 信用筹码；通用筹码不重置（跨轮累积）。  
6. 清除上一轮风险标记。

## 八、单轮完整流程（标准时序）

### 阶段 0｜准备（约 2 分钟）

入境者之间可：

- 私下交易通用筹码  
- 达成「互不游说」等协议  
- 交换符号手牌（双方同意即可）

**所有协议无规则约束力，可背刺。**  
检查员不参与入境者之间的交易（可旁听）；检查员可与入境者谈「未来放行意向」，无约束力。

### 阶段 1｜依次递交符号

按检查员左侧起顺时针：

1. 入境者打出 **1–2** 张符号，正面朝上置于个人区域。  
2. 仅可发言：**「我申请入境。」**  
3. 禁止解释符号、禁止暗示概念、禁止提及逻辑域或档案。

打出的符号构成本轮该玩家的**描述载体**；对照其秘则卡生成**本轮概念集合 Σ**（见 10.3）。Σ 对本人可见（秘则在手即可自查），对他人保密。

### 阶段 2｜双向贿赂谈判（约 3–5 分钟）

- 任意玩家可向检查员支付通用筹码（行贿）。  
- 检查员可公开或私下索贿。  
- **收钱不代表必须放行**；拒绝入境时，已收贿赂**不退**。  
- 合规者也可以行贿（迷雾、防游说、挤名额）。  
- 贿赂筹码放在检查员「本轮贿款区」；轮末归检查员个人（可留作终局兑换），**不**退回银行。

### 阶段 3｜破译质询（可与阶段 4 交错，按入境者逐个处理）

检查员指定一名尚未判决的入境者，消耗信用提问。

**唯一合法句式**：  
> 「你的符号所描述的特征，是否包含〔公共概念词〕？」

- 每问消耗 **1** 信用；信用为 0 不可再问。  
- 目标必须据实答「是」或「否」（依据本人本轮 Σ 是否含该概念）。  
- 对同一入境者全轮最多 **2** 次质询（防止信用全砸一人）。  
- 禁止复合问、禁止选择问、禁止「或者」、禁止问符号本身形状含义。

### 阶段 4｜边境游说（高对抗）

当检查员正在审核某入境者（已递交、未判决）时，**其他入境者**可发动游说：

1. 向银行支付 **2** 通用筹码。  
2. 将该入境者区域放置 **1** 枚风险标记。  
3. 仅可发言：**「此人存在风险，请谨慎判决。」**  
4. 禁止解读符号、禁止剧透概念、禁止暗示档案。

**同目标全轮最多 1 次成功放置的风险标记**（多人想游说同一人时：先支付者生效，后者筹码退回）。  
风险标记**不是**合法判决依据（铁则 5），仅心理干扰。

### 阶段 5｜检查员判决

对每名入境者宣布：**放行** 或 **拒绝**。

约束：

- 放行人数不得超过本轮名额（第七节）。  
- **名额是上限不是指标**：少放不扣分；不必用满。  
- 可以先问后判，也可以在名额满后对剩余人拒绝。  
- 零质询仍可判，但吃额外 -2。

### 阶段 6｜轮末统一开牌结算

1. 所有入境者同时公开：档案 + 秘则（逻辑域标签至少公开；完整对照表建议公开便于教学）。  
2. 按第九节计分。  
3. 检查员可提交本轮密猜（可选）：猜每名入境者的逻辑域 ∈ {S, M, H}；猜对每人 +1。  
4. 回收符号、秘则、档案、信用、风险标记；通用筹码保留。  
5. 轮换检查员，进入下一轮。

## 九、完整计分体系（v1.0）

### 9.1 入境者

| 事件 | 得分 | 说明 |
|---|---|---|
| 合规且放行 | **+2** | 成功履行「该进的人」 |
| 合规且被拒 | **+1** | 安慰分；**低于**成功入境，防刷「被冤拒」 |
| 违规且放行（偷渡成功） | **+3** | 高风险高收益 |
| 违规且被拒 | **0** | 基准；硬核变体见附录 B 可改 -1 |
| 游说：目标被拒，且目标**确实违规** | **+1** | 有效情报式施压 |
| 游说：目标被拒，但目标**其实合规** | **0** | 筹码已付给银行，不退 |
| 游说：目标仍被放行 | **0** | 筹码不退 |

### 9.2 检查员

对**每名**入境者分别结算，再求和。

| 事件 | 得分 |
|---|---|
| 正确放行合规 | **+1** |
| 正确拒绝违规 | **+1** |
| 误拒合规 | **-1** |
| 误放违规，且本轮**未**收过该人贿赂 | **-2** |
| 误放违规，且本轮**收过**该人至少 1 通用贿赂 | **-4** |
| 对该人零合法质询就判决 | 上列得分之外再 **-2** |
| 密猜其逻辑域正确 | **+1**（每人限猜一次） |

「本轮收过该人贿赂」：该入境者在阶段 2 向检查员支付过 ≥1 通用（无论之后是否退还——本规则不退还）。

### 9.3 终局兑换

局结束（所有人当完检查员）后：  
**每 3 枚通用筹码 → +1 分**（余数舍去）。  
鼓励交易与存钱，但不碾压破译主线。

### 9.4 无坐牢原则

任一轮无论身份与判决，入境者期望分非强制为负；检查员通过正确判决与破译加分可追分。不存在「整轮必亏且无操作」的座位。

## 十、编码与生成规则（闭环核心，禁止删改因果）

### 10.1 三段因果（锁死）

```
打出的符号  --(秘则对照表)-->  本轮概念集合 Σ
Σ + 本轮法令  --(法令算法)-->  法令视角下的「应允 / 应拒」
入境档案颜色 必须与「应允 / 应拒」一致（发牌约束）
检查员判决 与 档案 比较  -->  计分
```

玩家**不知道**别人的对照表；只知道自己的 Σ 与公开法令。

### 10.2 逻辑域定义

| 代号 | 名称 | 叙事含义 | 与档案默认关系 |
|---|---|---|---|
| **S** | 定居 | 稳定定居类事物 | 多数法令下倾向**合规** |
| **M** | 迁徙 | 移动、路途、游牧类事物 | 多数法令下倾向**违规** |
| **H** | 互助 | 庇护、互助、守望类事物 | 视法令：有时准入有时禁止 |

档案只有两种：**合规 / 违规**。逻辑域是破译对象；档案是胜负真值。

### 10.3 本轮概念集合 Σ 的生成

秘则卡背面（私密）提供：

- `逻辑域` ∈ {S, M, H}  
- 对每个符号 σ，给出一个**概念子集** Tag(σ) ⊆ 公共概念池  
- **合成规则（全游戏统一）**：  
  - 若打出 1 个符号 σ：`Σ = Tag(σ)`  
  - 若打出 2 个符号 σ, τ：`Σ = Tag(σ) ∪ Tag(τ)`  

质询「是否包含 X」⇔ `X ∈ Σ`。

### 10.4 发牌一致性约束（防自相矛盾）

每轮按以下**强制流程**发私密信息（可由一名玩家当「发牌员」或使用预组信封）：

1. 公开本轮法令 L。  
2. 根据 L 的「允许域 / 禁止域」，将秘则卡分为：**本轮可作合规的秘则** vs **本轮可作违规的秘则**。  
3. 决定本轮合规/违规人数倾向（建议）：  
   - 3 人局（2 入境者）：**1 合规 + 1 违规**（固定，保证有真偷渡压力）  
   - 4 人局（3 入境者）：**2 合规 + 1 违规** 或 **1 合规 + 2 违规**（法令卡上标注本轮配比；见法令表）  
4. 从对应池中随机发秘则；**文书档案颜色由逻辑域相对本轮允许/禁止域决定**（见 10.5.1；特殊条款不参与发牌染色）。  
   - 实现方式 A（推荐）：档案与秘则印成「一体信封」——抽到即逻辑域与文书色已匹配法令域划分。  
   - 实现方式 B：先抽逻辑域，再按法令域划分表发对应颜色文书。

**禁止**：独立随机抽档案再随机抽秘则导致「域已被禁止却发绿档」。  
**允许**：绿档玩家因 Σ 触发特殊条款，在开牌时按违规结算（10.5.1）。

### 10.5 法令卡模板与 6 张定稿

每张法令必须且仅含三行：

- **允许域**  
- **禁止域**  
- **特殊条款**（可「无」）  
- **本轮档案配比**（3 人局忽略配比行中的 4 人项；4 人局按此执行）

**法令判定算法（对每名入境者）**：

1. 取该玩家秘则逻辑域 D。  
2. 若 D ∈ 禁止域 → **应拒**。  
3. 否则若 D ∈ 允许域 → 进入特殊条款检查。  
4. 特殊条款若触发「强制应拒」→ **应拒**；若触发「强制应允」→ **应允**；否则 **应允**。  
5. 若允许域与禁止域划分后 D 落在未列出的域：视为禁止（安全默认）。本套 6 张法令已覆盖 S/M/H，无漏网。

#### 10.5.1 发牌档案 vs 开牌结算身份（v1.1 补丁，锁死）

发牌时的文书档案颜色，与开牌后的**结算身份**可以分离：

| 阶段 | 依据 | 用途 |
|---|---|---|
| **发牌** | 仅逻辑域 D × 本轮允许/禁止域（**暂不**把 Σ 特殊条款算进去） | 发绿/红文书；保证「域被禁者」必拿红档 |
| **开牌结算** | **完整算法**（D + 本轮 Σ 触发的特殊条款） | 决定应允/应拒，并据此计分 |

**覆盖规则**：

1. 若文书为合规（绿），但开牌时 Σ 触发「强制应拒」，则本轮**结算身份视为违规**：放行=偷渡成功（+3）；拒绝=违规被拒（0）。  
2. 叙事：申请符号触犯附加条款，现场否决文书。  
3. 持合规档的入境者应避免打出可能触发本轮特殊条款的符号（选牌自保微决策）。  
4. 检查员密猜对象仍是**逻辑域标签** {S,M,H}，不受结算身份覆盖影响。  
5. 计分比较的是「检查员判决」vs「开牌完整算法的应允/应拒」，不是 vs「文书印刷色」。

### 10.7 提问示例（合法 / 非法）

**合法**：  
- 「是否包含果实？」

- 「你是迁徙族吗？」  
- 「你能不能进？」  
- 「你的圆是不是河流？」  
- 「果实或火种有一个吗？」  

### 10.8 检查员推理指引（规则书可印，非隐藏信息）

1. 用 1–2 次「是/否」逼近 Σ 中高频概念。  
2. 对照本轮法令的允许/禁止域，形成「更像 S / M / H」的假说。  
3. 检查特殊条款是否可能触发（如是否像在藏「火种」）。  
4. 结合贿赂与风险标记做**心理**判断，但结算只认「完整法令算法下的应允/应拒」（见 10.5.1），不认贿赂与文书印刷色本身。  
5. 名额不足时：在「两个都像合规」的人里择一放行——此即合规内卷。名额是上限，不必用满。

## 十四、FAQ / 裁判条例（防争论）

1. **打出 2 符号后发现手牌更想换？** 不可收回；准备阶段交换须在递交前完成。  
2. **信用能否给别人？** 不能。  
3. **检查员能否问已判决的人？** 不能。  
4. **名额已满是否还要质询？** 规则不强制；但不质询就拒绝仍吃零质询 -2。  
5. **多人同时向检查员行贿？** 允许；分别记录「是否收过该人贿赂」。  
6. **协议「你放我我下轮放你」？** 允许说，无强制力。  
7. **能否问「是否包含果实和火种」？** 不能；拆成两次问。  
8. **Σ 为空可能吗？** 本套 Tag 均非空；打出合法符号则 Σ 非空。  
9. **法令特殊条款看 Σ，玩家要公开 Σ 吗？** 不要。结算时公开秘则与打出符号，由全员验算 Σ 与应允/应拒是否匹配发牌——若发牌正确，档案颜色必一致。  
10. **检查员自己上轮的筹码？** 通用跨轮保留；信用每轮重置。

- [ ] 合规玩家是否仍想「被拒刷分」？（v1.0 已压到 +1 < +2）

- [ ] 游说 2 费是否过贵/过贱？（穷玩家可能整轮无法游说）  
- [ ] L3/L4 特殊条款是否过难察觉（需命中关键词一问即可，推演中偏强而清晰）  
- [ ] 终局 3:1 兑换是否让存钱流压过检查员表现？（推演中兑换可改名次但不碾压）

# 《遗迹对峙》· Tabletop Simulator 导入步骤

本目录是可导入 TTS 的素材包（文字牌面，非精美插画）。  
**Cursor / 本仓库不能替你点击 Steam 里的 TTS**——下面每一步都在你电脑上的 Tabletop Simulator 里完成。

规则全文见：`Docs/殖民原住民说明书-v3.1.docx`  
文件清单见：本目录 `manifest.json`

**一键找图**：所有 PNG 已集中在本目录  
`全部图片-导入用/`（共 38 张）  
也可直接解压同目录的 `全部图片-导入用.zip`。

命名：`00-牌背.png` · `贡品-01-….png` · `版图-….png`

---

## 0. 开始前

1. Steam 已安装并启动过一次 **Tabletop Simulator**。  
2. 导入时选图请打开：  
   `...\Docs\TTS-遗迹对峙\全部图片-导入用\`  
3. TTS 读本地图有时不稳，**推荐**用游戏内 **Cloud** 上传图片（见第 2 步）。也可把 PNG 丢到可直链图床后再贴 URL。

---

## 1. 开一张空白桌

1. 打开 TTS → 主菜单。  
2. 选 **单人 / Host**（或创建房间）。  
3. **Games → Workshop / Saved** 里找空白桌，或：  
   **Objects → Components → Boards** 随便放一块板当桌面亦可。  
4. 建议：创意工坊搜 `Blank` / `Empty Table`，订阅一张空桌再开。

视角用鼠标右键拖、滚轮缩放。坐下：点击桌边座位颜色。

---

## 2. 导入 30 张贡品牌组（最重要）

### 方法 A：逐张 Custom Card 再组牌（最稳，适合新手）

1. 菜单 **Objects → Components → Cards → Custom Card**。  
2. Face：点文件夹图标，选  
   `全部图片-导入用/贡品-01-金字塔.png`  
3. Back：选 `全部图片-导入用/00-牌背.png`。  
4. 点 **Import**。桌上出现一张牌。  
5. 对 `02` … `30` 重复；或复制第一张后改 Face URL/路径。  
6. 把 30 张叠在一起：多选（Shift）→ 右键 → **Group**（或拖到一叠上）形成牌库。

### 方法 B：Custom Deck + Cloud（更快）

TTS 的 Custom Deck 通常要「多张面拼成一张大图」。第一版素材是**单张分文件**，所以新手优先方法 A。  
若你熟悉牌页：可用外部工具把 `01`–`30` 拼成 10×3 牌页后再用 Custom Deck。

**牌背统一**：所有贡品 Back 都用 `cards/back.png`。

---

## 3. 摆成 5×6 场地

1. 右键牌库 → **Spread** / 或一张张拖出。  
2. 摆成 **5 行 × 6 列**（共 30 张，全部正面朝上）。  
3. 对齐：多选一列 → 右键 → **Align**（若有）或手动靠齐。  
4. 可选：右键单卡 → **Lock**，避免碰乱（需要转 90° 学语言时先 Unlock）。

坐标约定：靠殖民者一侧为第 1 行或按你放的「进贡卡」方向对齐——**进贡卡必须与场地同向**。

---

## 4. 导入版图（Custom Tile）

对每个 PNG 做一次：

1. **Objects → Components → Custom → Tile**（或 **Board**）。  
2. Image：在 `全部图片-导入用/` 里选对应 `版图-….png`。  
3. Type 可选 **Rectangle**；Thickness 稍薄。  
4. Import 后拖到合适位置、缩放（按住鼠标缩放键或右键尺寸）。

| 文件 | 放哪 | 谁看得见 |
|---|---|---|
| `版图-格分图-5x6.png` | 场地旁 | 全桌 |
| `版图-组合加分表.png` | 场地旁 | 全桌 |
| `版图-计分表.png` | 桌边 | 全桌 |
| `版图-画符板-空白.png` | 殖民者面前 | 全桌（当众画符） |
| `版图-进贡卡-5x6.png` | 每位原住民面前各 1 份 | 标记时私密，亮牌时公开 |
| `版图-笔记板-16词.png` | 每位原住民 | **建议放进手牌区** |
| `版图-语言板-殖民者.png` | 殖民者 | **建议放进手牌区** |

复制物件：选中 → **Ctrl+C / Ctrl+V**（或右键 Clone）。原住民有几人就复制几份进贡卡、笔记板。

---

## 5. 私密信息怎么藏（语言板 / 笔记）

TTS 没有完美纸质屏风，第一版用：

1. 点自己座位坐下。  
2. 把「语言板」或「笔记板」拖到屏幕下方 **手牌区（Hand）**。  
3. 只有自己能看手牌区内容；别人视角看不到。

殖民者语言板里的符号＝**示范配对**；正式开局可约定每局重洗对应（或不管示范，当固定一局语言）。

---

## 6. 收物标记与笔

1. **Objects → Components → Tokens → Chip**（或 Chess 卒）。  
2. 殖民者甲一个颜色、乙另一个颜色，多复制几枚。  
3. 画符：选中「画符板」→ 用顶部 **Draw / 笔** 工具写符号；擦除用 Erase。  
4. 进贡标记：可用小 Token 放在进贡卡格子上的圆圈里，或用笔点。

---

## 7. 按规则试玩时的 TTS 操作对照

| 规则动作 | 在 TTS 里怎么做 |
|---|---|
| 转牌 90° 学语言 | 选中贡品 → 右键旋转（或用旋转键），**学完必须转回** |
| 至少转 2 张 | 自己遵守，素材无法强制 |
| 禁止交流 | 关语音 / 约定文字只喊「亮」「转回」「下一位」 |
| 进贡先标记再同时亮 | 各自在进贡卡上放标记（手牌区或桌前背面）→ 有人喊「亮」→ 一起公开 |
| 盖住已送出的贡品 | 殖民者把彩色 Chip 放到该贡品上，或把牌翻面/移到「已收」区 |
| 记分 | 对照 `计分表.png`，用记事本物件或 Chip 计数；终局再加 `组合加分表` |

## 8. 存成自己的模组

1. 摆好一桌（建议存「4 人开局布置」）。  
2. **Games → Save & Load → Save Game**。  
3. 名字例如：`遗迹对峙 TTS v1`。  
4. 本地一般在：  
   `文档\My Games\Tabletop Simulator\Saves\`  
5. 下次：**Games → Save & Load** 加载即可。

上传创意工坊（可选）：**Mods → Workshop Upload**（界面因版本略有差别）。上传前确认图片用 Cloud 或稳定外链，否则别人订阅后会裂图。

## 10. 常见问题

**Q：导入后是粉红图 / 裂图？**  
A：本地路径失效。改用 TTS Cloud 上传同一张 PNG，或图床直链。

**Q：Custom Deck 一次导入 30 张？**  
A：本包是单张文件。用方法 A，或自行拼牌页。

**Q：别人进房间看不到我的图？**  
A：图必须在 Cloud / 公网 URL；仅你电脑绝对路径时，客机加载失败。

**Q：以后要换成精美插画？**  
A：保持文件名不变，覆盖 `cards/01-….png` 等，再在 TTS 里重新 Import 或换图即可。

## 你现在只要做的三件事

1. 打开 TTS，开空白桌。  
2. 按第 2–4 步导入 `cards/` 与 `boards/`。  
3. **Save Game**，叫朋友进来按说明书玩一轮。

卡在某一步菜单名称不一致时：TTS 版本可能把 `Objects → Components` 写成中文「物件 → 组件」——找带 **Custom Card / Custom Tile** 的入口即可。

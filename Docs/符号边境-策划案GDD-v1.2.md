# 《符号边境》桌游策划案（GDD 格式 · v1.2）

> 双核定稿：**今日通告抽牌（Papers Please）× 具象破译（第一次接触）× 贿赂名额（诺丁汉）**。  
> **今日通告只做两件事（写死）**：抽到就生效——① 今日某**种族**不得入境；或 ② 符号描述涉及某**物品/种类**者不得入境。  
> 详细物牌归类 / 秘则表见后续总纲；本稿为策划案标准结构全文。

---

## 1. Game Identity / Mantra（一句话定位）

**每天抽一张通告：禁某个种族，或禁带某种东西；你用听不懂的诚实符号申请，我用桌上的实物逼你露馅。**

设计决策检验句：

- 若机制主要靠「说谎」成立 → 否决。  
- 若检查员可直接问「你是哪一族 / 你有没有火种」、跳过具象概括 → 否决。  
- 若通告不是「禁种族」或「禁物品」这两种可执行句 → 否决。

---

## 2. Design Pillars（设计支柱）

| 支柱 | 玩家应感到的情绪 / 体验 |
|---|---|
| **今日通告** | 像 Papers Please：每天抽牌，今天禁一族或禁一类货，执法目标清晰。 |
| **指物见义** | 像第一次接触：只给苹果、篝火、渡船，你必须自己概括对方符号在说什么。 |
| **刀下名额** | 收钱、游说、抢坑位都真实，但判决仍要扛「通告 + 名额」的公职压力。 |

**支柱用法**：新功能须服务至少一条；通告若写成复杂多条件公文，视为 scope creep——保持「禁种族 / 禁物品」二选一。

---

## 3. Genre（类型与对标，含桌游 3C）

### 3.1 类型标签

- 主类型：**不对称角色轮替 / 社交推理桌游**
- 副类型：每日规则事件、具象语义破译、轻经济贿赂、个人竞技
- 人数：3–4（正式）；时长：约 33–42 分钟
- 品类：Strategy 内核 + Party 外交皮

### 3.2 桌游版「3C」

| 3C | 本游戏对应 |
|---|---|
| **Character** | 轮替座位：检查员 vs 入境者；入境者持私密秘则（逻辑域 S/M/H）+ 文书（合规/违规）+ 符号句（根/饰）。 |
| **Camera** | 信息视角 = 公开今日通告与物牌展台 + 破译板假说 + 私密秘则/文书/手牌。 |
| **Control** | 抽通告、摆符号、推筹码、指物牌提问、写破译板、宣判放行/拒绝、游说标记。 |

### 3.3 三个对标竞品

| 竞品 | 对标层 | 借什么 | 故意不同 |
|---|---|---|---|
| **《Papers, Please》** | 顶层压力 | 每日抽规定：禁某族 / 禁某物、误判恐惧 | 落成多人桌面通告牌；对抗来自其他玩家 |
| **《Arrival》/第一类接触** | 底层破译 | 具象刺激→概括词义、渐进词库 | 每轮换私语；限时信用；绑定通告执法 |
| **《诺丁汉警长》** | 中层博弈 | 贿赂、收钱不保证放行、轮替权力、背刺 | 「袋子」换成符号语言；贿赂非法化为判决依据 |

品类句：**会说话的诺丁汉 × 指物破译的第一次接触 × 每日抽牌禁令的 Papers Please。**

## 4. Story & Characters（故事与角色）

### 4.1 Story Synopsis

边境口岸接通三种异族文明：**定居族、迁徙族、互助族**。各族没有通用文字，只用古老几何符号写成短句。帝国每天抽发一张通告——今天可能写「迁徙族一律不得入境」，明天可能写「描述中涉及火种者不得入境」。

旅客必须打出符号申请，却不能解释。检查员不能直接问「你是哪一族」或「你有没有火种」，只能指着桌上的苹果、篝火、渡船问：「这件东西算不算你在说的？」诚实的是/否逼他概括：对方到底属于哪一族、话里有没有今日禁物。

名额永远不够。被今日通告盯上的人要行贿、伪装、躲指物；检查员要在禁族与禁物之间刀下去。轮替之后，昨日的入境者成为今日的检查员。

最终留下的不是「谁更会说谎」，而是谁更能在今日通告下读懂一句陌生的诚实。

### 4.2 角色设定

#### 三种种族（逻辑域，公开世界观 / 私密归属）

| 种族名 | 代号 | 符号语言倾向（叙事） |
|---|---|---|
| **定居族** | S | 稳定资源、家园、石门与羊群 |
| **迁徙族** | M | 道路、航行、原野与路途 |
| **互助族** | H | 守望、庇护、石门与灯火 |

每人每轮秘密属于其中一族（秘则自带种族标签）。检查员须通过破译推断，**禁止直问种族**。

#### 检查员（轮替公职）

- **职责**：读今日通告；用物牌破译；判断对方是否「禁族」或「带禁物」；名额内判决。  
- **资源**：信用、贿赂、破译板、翻译宣读。  
- **压力**：误放通告禁止对象重罚；受贿再误放更重；名额残忍。  

#### 入境者（本轮申请方）

- **持有**：种族（S/M/H）+ 文书色 + 符号句（决定你「话里有哪些物品种类」）。  
- **可做**：选符号控制「像不像禁族 / 像不像带禁物」；行贿；交易；游说；诚实答指物。  
- **不可做**：说谎；直宣种族；解释符号；游说时点名通告细则剧透破译。

#### 关系

无固定阵营；个人计分。结构对抗：检查员↔入境者；入境者↔入境者（名额/游说）。信息对抗：私语不可跨人套用。

## 5. Mechanics Summary（机制总览）

### 5.1 游戏是什么

每轮**抽 1 张今日通告**：要么「某种族不得过」，要么「符号里沾到某物品不得过」。入境者打出私密符号申请；检查员用物牌诚实指问、概括对方种族与是否带禁物，再结合贿赂与名额判决。每人当一次检查员，总分最高胜。

### 5.2 基本规则

#### 能做什么

| 角色 | 行动 |
|---|---|
| 全员 | 读今日通告；看展台物牌；跨轮持通用筹码 |
| 入境者 | 交易/换牌/口头协议；打出 1–2 符号；行贿；答指物是/否；游说他人 |
| 检查员 | 索贿/收贿；耗信用指物问；写破译板；判决；翻译宣读 |

#### 不能做什么

- 说谎或拒答合法指物问  
- 直问「你是哪一族」「你有没有〔禁物〕」「你能不能进」  
- 质询时直接点名抽象种类词（必须通过指物概括）  
- 把他人符号译法套到另一人身上  
- 超过名额放行  
- 游说时解读符号或宣读通告结论替检查员破译  

#### 胜负

- 结束：轮数 = 人数  
- 胜利：个人总分最高；同分比检查员正确判决次数  
- 无组队胜负、无中途淘汰出局  

### 5.3 双层语义（破译内核）

| 层 | 内容 | 桌上可见性 |
|---|---|---|
| 具象层 | 物牌：苹果、篝火、渡船、哨塔… | 展台公开；牌面不印抽象类 |
| 抽象层 | 10 种物品类：河流、果实、岩壁、火种、道路、羊群、石门、原野、航行、守望 | 用于「禁物品」通告、秘则、归类表、翻译宣读 |

**归类表（验算用）**：每物 → 1～2 物品类。例：苹果→果实；篝火→火种；渡船→航行,河流。  
**指物判定**：答「是」⇔ 该物物品类 ∩ 本轮 Σ ≠ ∅。

检查员用一连串是/否去概括两件事：  
1）对方更像哪一族；2）对方话里有没有今日禁物。

### 5.4 根饰语法（符号句）

秘则每符号：主义 Primary（1 物品类）+ 辅义 Secondary（2 物品类）；秘则同时印有**种族** S/M/H。

- 打 1 符：根；Σ = {Primary}∪Secondary  
- 打 2 符：先根后饰；R = 根之全集；M = {Primary饰}；Σ = R∪M  

「手里有没有 xx 物品」在规则上 = **Σ 是否包含该物品类**（通过符号语言表达，不是另抽物品手牌）。

### 5.5 今日通告（每天抽牌 · 核心写死）

每轮开局从通告库**抽 1 张**，公开置于中央，整轮有效。  
牌面只有两种模板，模仿 Papers Please「今天起……不得入境」：

---

**类型 A｜禁种族**

> 通告：自即日起，**〔定居族 / 迁徙族 / 互助族〕**不得入境。  
> 规则：该种族入境者 → **应拒**；其余种族 → **应允**（仍受名额限制）。

---

**类型 B｜禁物品**

> 通告：自即日起，申请描述中涉及 **〔某物品类〕** 者不得入境。  
> 规则：若 Σ 含该物品类 → **应拒**；否则看种族是否另有限制——本类型默认**不禁种族**，未触物品则 **应允**。

---

**开牌结算（极简）**：

1. 若通告是 **禁种族** 且入境者种族命中 → 应拒。  
2. 若通告是 **禁物品** 且 Σ 含该物品类 → 应拒。  
3. 否则 → 应允。  
4. 「应允」仍可能因名额被拒（名额是上限）；计分上：应允被拒 = 合规被拒安慰分；应拒被放 = 偷渡/误放。

发牌：按本轮通告预分配「今日应允 / 应拒」人数（建议 4 人局：约 1～2 人触禁），保证桌上有人真正撞线。

**通告库（12 张定稿）**

| 编号 | 类型 | 通告正文（桌上可见） |
|---|---|---|
| N1 | 禁种族 | 定居族不得入境 |
| N2 | 禁种族 | 迁徙族不得入境 |
| N3 | 禁种族 | 互助族不得入境 |
| N4 | 禁物品 | 涉及**火种**者不得入境 |
| N5 | 禁物品 | 涉及**航行**者不得入境 |
| N6 | 禁物品 | 涉及**果实**者不得入境 |
| N7 | 禁物品 | 涉及**道路**者不得入境 |
| N8 | 禁物品 | 涉及**原野**者不得入境 |
| N9 | 禁物品 | 涉及**石门**者不得入境 |
| N10 | 禁物品 | 涉及**羊群**者不得入境 |
| N11 | 禁物品 | 涉及**守望**者不得入境 |
| N12 | 禁物品 | 涉及**河流**者不得入境 |

（岩壁可并入 N 扩展或替换其一；正式盒取满 10 物品类各至少 1 张禁物通告 + 3 张禁族。）

**展台联动**：抽到禁物品通告时，展台必须包含 ≥1 张归类命中该物品的物牌（如禁火种 → 必有篝火或火把），保证检查员「有物可指」。禁种族通告则展台按各族倾向物混洗即可。

### 5.6 数值系统

| 数值 | 作用 | v1.2 基准 |
|---|---|---|
| 总分 | 胜负 | 入境 + 检查 + 破译 + 兑换 |
| 通用筹码 | 贿赂/游说/交易/终局兑分 | 起始 5（4 人）/ 6（3 人）；3 筹=1 分 |
| 信用 | 指物提问 | 每轮 **4**；同人最多 **3** 问 |
| 名额 | 放行上限 | 3 人局 1；4 人局 2（上限非指标） |
| 展台 | 可指物 | 每轮 8 张；禁物通告强制补位 |
| 破译加分 | 翻译宣读 | 猜对根符 Primary +2/人（同人破译上限 +2） |

### 5.7 经济

- 产生：开局发放；贿赂为玩家间转移  
- 消耗：游说付银行 2；信用轮末回收  
- 通胀：筹码池固定；兑换 3:1  
- 误放「通告应拒者」：−2；若收过该人贿赂再 −2（合计 −4）

### 5.8 「物理 / AI」

- 桌面分区：通告区、展台、申请区、贿款区、破译板、弃牌  
- 规则算法 = 裁判 AI：通告类型判定 → 计分；归类表消除验算争议  

### 5.9 双方博弈要点

**入境者**  
- 禁种族日：用符号语言「装成」另一族的描述习惯，误导检查员。  
- 禁物品日：选符号让 Σ **躲开**今日禁物；或违规者故意擦边赌检查员指错。  
- 行贿、防游说。

**检查员**  
- 禁种族日：用物牌探测对方描述像哪一族，再决定拒谁。  
- 禁物品日：优先指与禁物相关的展台牌；答「是」→ 高概率应拒。  
- 收钱仍可拒；名额下刀。

### 5.10 游戏循环

**核心循环（单轮）**  
抽今日通告 → 补展台 → 发种族/秘则/符号 → 交易 → 递交符号 → 贿赂 → 指物概括（查禁族或禁物）→ 游说 → 判决 → 宣读与开牌计分 → 留筹 → 轮替。

**次要循环**：交易换牌；终局兑换；角色轮替。

**宏循环**：开局 → 核心循环 × 人数 → 兑换 → 排名。

## 6. Features / USP（独特卖点）

1. **无人说谎**：欺骗只来自私语不互通。  
2. **每天抽牌，两种禁令**：禁种族 **或** 禁物品——Papers Please 一样好懂。  
3. **指物见义**：用实物概括「是哪族 / 有没有禁物」，禁止直问。  
4. **检查↔被检查闭环**：躲通告 vs 查通告，博弈可读。  
5. **收贿不保证放行**：合规也行贿；收钱仍可刀。  
6. **名额刀锋**：上限制造正确却残忍的拒绝。  
7. **破译板可见学习过程**。  
8. **翻译宣读顿悟分**。  
9. **三重融合无割裂**：每日通告 × 语义破译 × 交易背刺。  
10. **轮替公平个人竞技**。

## 7. Interface（交互界面）

> 桌游 UI = 今日通告 + 物牌展台 + 破译板 + 发言协议 + 记分。

### 7.1 Controls（输入）

| 输入 | 方式 |
|---|---|
| 今日规定 | **抽 1 张通告**置于中央（禁种族或禁物品） |
| 展台 | 翻 8 物；禁物品通告时检索补位相关物 |
| 递交 | 根符在左/上，饰符在右/下 |
| 指物问 | 口述固定句 + 点展台一物 + 付 1 信用 |
| 回答 | 「是」/「否」 |
| 破译板 | 写「像迁徙族?」「可能有火种?」等概括 |
| 贿赂 | 筹码推入贿款区 |
| 游说 | 付 2 + 风险标记 + 固定台词 |
| 判决 | 「放行」/「拒绝」 |
| 翻译宣读 | 口述根符主义物品类 |

### 7.2 信息显示

| 层级 | 内容 |
|---|---|
| 公共 | 通告、展台、已测物、符号面、风险标记、信用、名额、破译板 |
| 私密 | 秘则（含种族）、未打出符号、个人筹码 |
| 结算 | 公开种族与 Σ；对照通告验算应允/应拒 |

### 7.3 界面类型

| 类型 | 体现 |
|---|---|
| Diegetic | 通告公文、物牌、符号、关防筹码 |
| Non-Diegetic | 积分表、归类附录（开牌用） |
| Spatial | 展台/申请区/贿款区分区 |
| Meta | 破译板 |

### 7.4 反馈

- 听觉：申请句、风险句、宣读句  
- 视觉：通告大红禁戳（族名或物名）；物牌翻倒  
- 社交：行贿与沉默  

### 7.5 原则

清晰（通告两种模板，一行禁令）；无障碍（符号高对比）；效率（指物句印辅助卡）；沉浸（公文 + 碑文 + 静物）。

## 8. Art Style（美术风格）

### 8.1 总方向

**「边境每日通告 × 异族碑文符号 × 静物标本展台」**

### 8.2 关键词

- 通告纸、关防印、红色「禁」戳（打在族名或物名上）  
- 几何圣符、拓片秘则  
- 物牌：清晰静物，不印物品类名  
- 低饱和；禁红、通告墨色  

### 8.3 分组件

| 组件 | 风格 |
|---|---|
| 今日通告 | 两种版式：禁族版 / 禁物版；正文一句，极大可读 |
| 具象物牌 | 单物居中、标本感 |
| 符号卡 | 大几何符 |
| 秘则 | 种族标签 + Primary/Secondary 表 |
| 破译板 | 可擦工作区 |
| 筹码 | 信用=官徽；通用=通行币 |

### 8.4 避免

- Q 版派对风；霓虹赛博；通告写成多条件长公文  

### 8.5 情绪板

**每天抽一张纸：今天禁一族，或禁一样东西——其余全靠你指着实物去听懂对方。**

# 《符号边境》桌游策划案（GDD 格式 · v2.0）

> **废止族群设定。** 不再有定居族/迁徙族/互助族，不再有「描述更像哪一族」的软推断。  
> 定稿三角：**今日通告只禁物品（Papers Please）× 具象物牌硬破译（第一次接触）× 贿赂名额（诺丁汉）**。  
> 检查员只查一件硬事实：对方这句符号描述里，有没有今日禁物。

---

## 1. Game Identity / Mantra（一句话定位）

**每天抽一张通告，写明哪种东西不能过；你用私密符号申请，我只能指着桌上的实物问算不算——答是答否都诚实，懂不懂靠我自己概括。**

设计决策检验句：

- 若机制依赖说谎 → 否决。  
- 若检查员可直接问「你有没有火种」→ 否决（必须指物）。  
- 若出现种族/阵营/「更像某族」软判定 → 否决。  
- 若通告不是「禁〔物品类〕」→ 否决。

---

## 2. Design Pillars（设计支柱）

| 支柱 | 玩家应感到的情绪 / 体验 |
|---|---|
| **今日禁物** | 像 Papers Please：通告一句「涉及火种者不得入境」，目标清晰、可执行。 |
| **指物见义** | 像第一次接触：只给篝火、苹果、渡船，用是/否硬推有没有禁物。 |
| **刀下名额** | 贿赂与游说真实存在，但改变不了「触禁=应拒」与名额上限。 |

**支柱用法**：新功能须服务至少一条。任何「猜身份气质」类规则视为 scope creep。

---

## 3. Genre（类型与对标，含桌游 3C）

### 3.1 类型标签

- 主类型：**不对称轮替 / 语义推理桌游**
- 副类型：每日禁令事件、具象破译、轻经济贿赂、个人竞技
- 人数：3–4；时长：约 30–40 分钟
- 品类：Strategy 内核 + 社交外交皮

### 3.2 桌游版「3C」

| 3C | 本游戏对应 |
|---|---|
| **Character** | 轮替：检查员 vs 入境者。入境者持私密「符号语言秘则」+ 本轮符号手牌；无种族标签。 |
| **Camera** | 公开：通告、物牌展台、打出的符号、破译板。私密：秘则、未打出的手牌。 |
| **Control** | 抽通告、出符号、推筹码、指物提问、写破译板、判决、游说。 |

### 3.3 三个对标竞品

| 竞品 | 对标层 | 借什么 | 故意不同 |
|---|---|---|---|
| **《Papers, Please》** | 顶层 | 每日禁令、误放惩罚 | 多人桌；禁令简化为「禁物品类」一句 |
| **《Arrival》/第一类接触** | 底层 | 具象刺激→概括含义 | 每轮换私语；只服务「有没有禁物」 |
| **《诺丁汉警长》** | 中层 | 贿赂、收钱不保证放行、轮替 | 查的不是袋子货，是符号语义 |

品类句：**指物破译的第一次接触 × 每日禁货的 Papers Please × 会说话的诺丁汉。**

## 4. Story & Characters（故事与角色）

### 4.1 Story Synopsis

边境口岸没有通用文字。每个申请者用自家几何符号写成一句「我是什么」——但符号只对本人有意义。帝国每天抽发通告：今日起，申请描述中涉及某种事物者不得入境。昨日禁的是航行，今日可能是火种。

检查员不能听懂符号，也不能直问「你有没有火种」。他只能把篝火、渡船、苹果摆上桌，问：「这件东西，算不算你在说的？」对方必须诚实回答是或否。检查员在破译板上写下概括，赌自己有没有挖出今日禁物，再在名额与贿赂的压力下刀下去。

没有「哪个种族」——只有「这句话里有没有今天不该有的东西」。轮替之后，昨日的申请者成为今日的检查员。

### 4.2 角色设定

#### 检查员（轮替公职）

- **唯一执法问题**：对方本轮符号描述（Σ）是否包含今日禁物类。  
- **手段**：指物问、破译板、贿赂心理、名额取舍。  
- **压力**：漏放触禁者重罚；受贿再漏放更重；名额可能逼你拒掉干净的人。

#### 入境者（本轮申请方）

- **持有**：私密秘则（符号→物品类对照）+ 符号手牌。  
- **本轮真相**：打出符号后生成 Σ；Σ 含今日禁物 = **触禁（应拒）**；否则 = **清洁（应允）**。  
- **可做**：选符躲禁物或擦边伪装；行贿；交易换牌；游说；诚实答指物。  
- **不可做**：说谎；解释符号；直说「我有/没有禁物」；替检查员完成破译结论。

#### 关系

无固定阵营、无族群。个人计分。对抗轴：检查员↔入境者；入境者↔入境者（名额/游说）。

## 5. Mechanics Summary（机制总览）

### 5.1 游戏是什么

每轮抽一张**今日通告（只禁物品类）**。入境者用私密符号打出申请句。检查员用展台物牌做是/否提问，硬推对方有没有触禁，再结合贿赂与名额判决。每人当一次检查员，总分最高胜。

### 5.2 基本规则

#### 能做什么

| 角色 | 行动 |
|---|---|
| 全员 | 读通告；看展台；持通用筹码 |
| 入境者 | 交易/换牌；出 1–2 符号；行贿；答指物；游说 |
| 检查员 | 索贿/收贿；指物问；写破译板；判决；翻译宣读 |

#### 不能做什么

- 说谎或拒答合法指物问  
- 直接问「有没有〔禁物类名〕」「能不能进」  
- 跨人套用符号含义  
- 超过名额放行  
- 任何种族/阵营判定  

#### 胜负

- 轮数 = 人数  
- 个人总分最高胜；同分比检查员正确判决次数  

### 5.3 双层语义（唯一破译轴）

| 层 | 内容 | 可见性 |
|---|---|---|
| 具象 | 物牌（苹果、篝火、渡船…） | 展台公开；**不印**物品类名 |
| 抽象 | 10 物品类：河流、果实、岩壁、火种、道路、羊群、石门、原野、航行、守望 | 通告禁令、秘则、归类表、宣读用 |

**归类表（开牌验算，质询时入境者私查）**  
例：篝火→火种；火把→火种；苹果→果实；渡船→航行,河流；哨塔→守望；车辙→道路…

**指物判定（硬）**  
检查员指物 E，问：「此物是否落在你的符号描述之内？」  
答「是」⇔ `categories(E) ∩ Σ ≠ ∅`。  
答「否」⇔ 无交集。  
开牌用归类表+秘则+打出符号验算，无「像不像」争议。

### 5.4 符号句与 Σ（无种族）

秘则：每个符号有 **主义 Primary（1 类）** + **辅义 Secondary（2 类）**。

- 出 1 符：Σ = {Primary} ∪ Secondary  
- 出 2 符：先出为根、后出为饰；Σ =（根之三类）∪ {饰的 Primary}

入境者在知通告后选符：清洁者尽量让 Σ 躲开禁物；赌徒可故意擦边或无法躲开只能贿。

### 5.5 今日通告（只禁物品 · 写死）

每轮抽 **1 张**，公开。模板唯一：

> 通告：自即日起，申请描述中涉及 **〔物品类〕** 者不得入境。

少数牌可写两类（双禁日），仍是物品，不是种族。

**开牌结算（硬）**

1. 若 `Σ ∩ 今日禁物 ≠ ∅` → **应拒**  
2. 否则 → **应允**  
3. 应允仍可能因名额被拒（名额=上限）  
4. 判决对错只对照上述结果，不对照任何族群

**发牌约束（保证桌上有戏）**

- 4 人局 3 名入境者：建议 **1～2 人** 的秘则在「常见出法」下容易触禁（或手牌迫使触禁），**1～2 人** 明确存在躲禁出法。  
- 具体用「清洁秘则包 / 夹带倾向秘则包」按通告检索发放——**包内只有物品对照，无种族栏**。

**通告库（12 张示例定稿）**

| 编号 | 通告正文 |
|---|---|
| N1 | 涉及**火种**者不得入境 |
| N2 | 涉及**航行**者不得入境 |
| N3 | 涉及**果实**者不得入境 |
| N4 | 涉及**道路**者不得入境 |
| N5 | 涉及**原野**者不得入境 |
| N6 | 涉及**石门**者不得入境 |
| N7 | 涉及**羊群**者不得入境 |
| N8 | 涉及**守望**者不得入境 |
| N9 | 涉及**河流**者不得入境 |
| N10 | 涉及**岩壁**者不得入境 |
| N11 | 涉及**火种或航行**者不得入境（双禁） |
| N12 | 涉及**道路或原野**者不得入境（双禁） |

**展台联动**：抽到某禁物后，展台 8 张中必须含 ≥1 张归类命中该禁物的物牌，保证检查员「有物可指」。

### 5.6 检查员如何推断（只保留硬路径）

**目标**：判断 Σ 是否含今日禁物。

**步骤**：

1. 看通告禁的是哪一类（如火种）。  
2. 优先指展台上归类可能属于该类的物（篝火、火把）。  
3. 「是」→ 触禁嫌疑极高 → 倾向拒绝。  
4. 「否」→ 再指另一张同类物交叉验证；仍否 → 倾向清洁、可放行。  
5. 信用不够或仍模糊 → 结合贿赂与名额做风险决策；开牌按硬规则算分。

**明确删除**：根据「描述气质」猜族群；任何族特征集；禁种族通告。

可选加分：轮末翻译宣读「你的根符主义是〔物品类〕」，猜对 +2（破译奖，非执法必需）。

### 5.7 数值系统

| 数值 | 作用 | 基准 |
|---|---|---|
| 总分 | 胜负 | 入境 + 检查 + 破译 + 兑换 |
| 通用筹码 | 贿/游说/交易/兑分 | 起始 5（4 人）/ 6（3 人）；3 筹=1 分 |
| 信用 | 指物 | 每轮 4；同人最多 3 问 |
| 名额 | 放行上限 | 3 人局 1；4 人局 2 |
| 展台 | 可指物 | 8 张/轮 |

**计分（入境者）**

| 事件 | 分 |
|---|---|
| 清洁且放行 | +2 |
| 清洁且被拒（名额/误判） | +1 |
| 触禁且放行（偷渡成功） | +3 |
| 触禁且被拒 | 0 |
| 游说：目标被拒且目标确触禁 | +1 |

**计分（检查员）**

| 事件 | 分 |
|---|---|
| 正确放行清洁 / 正确拒绝触禁 | 各 +1 |
| 误拒清洁 | −1 |
| 误放触禁 | −2；若收过该人贿赂再 −2 |
| 对该人零质询就判 | 额外 −2 |
| 翻译宣读根义正确 | +2（每人至多一次） |

### 5.8 经济与「裁判 AI」

- 贿赂转移筹码，不退；不作合法判决依据。  
- 游说费 2 进银行。  
- 验算只认：通告禁物 ∩ Σ。  

### 5.9 双方博弈（无族群版）

**入境者**  
- 知通告 + 知自己能否躲禁 → 选符、换牌、行贿、防游说。  
- 躲不开 → 当偷渡线，赌检查员指错或不敢拒受贿对象。  
- 对他人：听指物是/否，游说「看起来已露馅」的人，抢名额。

**检查员**  
- 围着禁物指展台。  
- 「是」就刀；「否」就放或继续验证。  
- 名额满时，在多个「像清洁」的人里残忍二选一。

### 5.10 游戏循环

抽通告 → 补展台 → 发秘则/符号 → 交易 → 出符号 → 贿赂 → 指物破译 → 游说 → 判决 → 宣读/开牌计分 → 留筹 → 轮替。

宏循环：重复至每人当过检查员 → 筹码兑分 → 排名。

## 6. Features / USP（独特卖点）

1. **无人说谎**，欺骗来自语言不互通。  
2. **通告极简**：每天只禁物品，好懂好执行。  
3. **无族群**：砍掉无法运作的软推断。  
4. **指物硬破译**：是/否 + 归类表，开牌可验算。  
5. **检查↔被检查**：躲禁物 vs 查禁物。  
6. **收贿不保证放行**。  
7. **名额刀锋**。  
8. **破译板可见学习过程**。  
9. **三重融合**：禁令 × 破译 × 交易，无割裂。  
10. **轮替公平个人竞技**。

## 7. Interface（交互界面）

### 7.1 Controls

| 输入 | 方式 |
|---|---|
| 通告 | 抽 1 张公开（禁〔物品类〕） |
| 展台 | 8 物；按禁物补位 |
| 出牌 | 1–2 符号（根/饰顺序） |
| 质询 | 「此物是否落在你的符号描述之内？」+ 指物 + 1 信用 |
| 回答 | 是 / 否 |
| 破译板 | 写「篝火=是→触火种?」 |
| 贿/游说/判决 | 同前版仪式句 |

### 7.2 信息显示

| 层级 | 内容 |
|---|---|
| 公共 | 通告、展台、符号面、是/否过程、破译板、名额、信用 |
| 私密 | 秘则、手牌 |
| 结算 | 公开 Σ 与是否触禁 |

### 7.3 原则

清晰（通告一句）；可验算（归类表）；禁止直问禁物类名；无种族 UI。

## 8. Art Style（美术风格）

### 8.1 方向

**边境每日禁物通告 × 碑文符号 × 静物标本展台**  
不画种族旗帜、不画族徽、不靠服饰辨族。

### 8.2 关键词

通告大红「禁」戳打在物名上；几何符；静物标本感物牌；公文灰绿与墨色。

### 8.3 组件

| 组件 | 风格 |
|---|---|
| 通告 | 一句禁令，极大字体 |
| 物牌 | 单物居中，不印类名 |
| 符号 | 大几何 |
| 秘则 | 仅 Primary/Secondary 表，**无种族栏** |
| 破译板 | 可擦 |

### 8.4 情绪板

**今天禁的是一样东西——不是一群人。听懂对方那句话里有没有它，就是全部游戏。**
